# Nexora 3D

A responsive, dark black-and-electric-blue website studio landing page built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and contact links
- `style.css` — responsive layout, animations and 3D-style effects
- `script.js` — mobile navigation, year display and pointer interaction

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your business email.
2. Replace `2348000000000` in the WhatsApp link with your number, including country code, with no plus sign or spaces.
3. The portfolio cards are concept demonstrations, not client projects. Keep that clear until you replace them with real work.
4. The digital shop is a preview. Add your real Selar product URL when your product is ready.

## Publish with GitHub Pages
1. Create a new **public** repository named `nexora-3d`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under build/deployment source choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the published link shown on the Pages settings screen.

Free static hosting does not itself process payments. Use a checkout provider such as Selar for product payments and delivery, then link to your product from the website.
